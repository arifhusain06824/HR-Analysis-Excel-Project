# 📊 HR Analytics Dashboard - Excel Project

An end-to-end HR Analytics project in Excel analyzing employee demographics, attrition, performance, and department-wise metrics.

## 🎯 Project Objective
To analyze HR data to uncover insights on employee turnover, demographics, satisfaction levels, and department performance. The goal is to provide actionable insights to improve retention and workforce management.

## 🛠️ Tools & Techniques Used
- **Microsoft Excel** (Pivot Tables, Slicers, Charts)
- **Advanced Formulas:** `INDEX-MATCH`, `XLOOKUP`, `FILTER`, `COUNTIFS`, `AVERAGEIF`, `SUMIFS`
- **Data Cleaning** (Handling missing values, standardizing text)
- **KPI Dashboards & Reporting**

## 📁 Dataset Overview
- **Total Records:** 311 Employees
- **Key Fields:** Employee Name, Department, Salary, Tenure, Performance Score, Satisfaction, Termination Reason, Demographics.
- **Departments:** Production, IT/IS, Software Engineering, Admin Offices, Sales, Executive Office.

## 📈 Key Performance Indicators (KPIs)
| Metric | Value |
|--------|-------|

| Avg Satisfaction | 3.8 (Calculate from file) |

## 🔍 Key Insights (From Analysis)
- **Production** department has the highest number of employees and the highest turnover.
- **Employee Referral** and **Indeed** are the top recruitment sources.
- **More Money** and **Unhappy** are among the top voluntary termination reasons.
- **IT/IS** and **Software Engineering** departments have the highest average salaries.


## 🚀 How to Use
1. Download the `HR Analysis.xlsx` file.
2. Open in Microsoft Excel (2016 or later).
3. Explore the sheets: `HR_DATA` → `HR Metrics (KPI Summary)` → `Department-wise Analysis` → `Demographics` → `Termination Reason Analysis` → `Advanced Insights`.
